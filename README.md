# CHHS Migration — Component Guides

Static reference pages comparing the components in use on the CSU CHHS / RDC WordPress themes with the destination framework (Find Your Energy theme + Stalwart Blocks plugin).

- `index.html` — start here
- `guide-chhs-theme.html` — current CHHS theme (ACF slabs)
- `guide-rdc-theme.html` — current RDC theme
- `guide-find-your-energy.html` — destination framework

Pure static HTML; theme CSS/fonts/images are copied under `assets/`. Open `index.html` locally or serve via GitHub Pages.

Component Guide — CSU CHHS theme (CURRENT)

← All guides

What this is

Reference guide to every component currently in use by the CSU CHHS theme (parent csu-chhs-parent-theme + child csu-chhs-theme), active on 36 sites including the main site. Each section starts with a yellow label stating what the component is, where its code lives, which ACF fields drive it, how often it's used, example live pages, and the closest match in the destination framework (Find Your Energy + Stalwart Blocks). The example renders below use the theme's real CSS with sample content.

Key point: these themes register no Gutenberg blocks. Content is built from ACF flexible-content "slabs" (section C) rendered by Timber/Twig. Example links open on your Local site (https://chhs.local).

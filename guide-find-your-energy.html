What this page is

This is a static Component Guide for the DESTINATION framework: the Find Your Energy (FYE) WordPress theme (v1.0.55) plus the Stalwart Blocks plugin (v1.1.22). Open it in a browser and compare it side by side with the legacy CHHS theme guide.

Neither the theme nor the plugin is active on any site yet. Every demo below is a static rendering of the markup WordPress would output, styled with the real compiled theme CSS (style.css), the WordPress core block-library CSS, and each Stalwart block's own CSS, all linked by relative path. Dynamic blocks (SOURCE Stories, Content Query, Trumba Events) use dummy data. Sliders, sticky nav, expander and swipe cards run with the plugin / theme JS.

Each section begins with a yellow label panel: what the component is, how it is registered, where its source lives, its options / ACF fields, and its legacy CHHS equivalent (direct / partial / gap), followed by the demo.

Content Query (default)

BLOCK

What it is
Queries any registered post type and displays results as a filterable grid of cards (or a table) with optional ribbon / pill / kicker term displays.
Registered as
stalwart-blocks/content-query
Source
stalwart-blocks/blocks/content-query/{block.json, content-query.php, content-query.css, content-query-frontend.js} stalwart-blocks/templates/cards/default.php stalwart-blocks/includes/card-template.php
Options / fields
  • Post Type (postType, string)
  • Display Mode (displayMode: all / curated / pre-filtered; curatedIds[])
  • Filters (filters[]: taxonomy, terms, withinOperator, showOnFrontend, inputType checkboxes / radio / dropdown, label, defaultTerms); acrossOperator AND / OR
  • Columns (columns, default 3); Posts per page (postsPerPage, -1 = all); Order by (title_asc / title_desc / newest / oldest / menu_order)

  • Term Displays (termDisplays[]: taxonomy, style ribbon / pills / kicker, placement, maxTerms)
  • Layout (grid or table) + Table Columns (tableColumns[])
  • Block attributes + editor JS, server-rendered by a render callback (no ACF fields)
  • Supports: align (wide, full), anchor, customClassName

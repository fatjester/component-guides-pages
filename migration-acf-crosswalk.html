Legacy slabs and sidebar repeaters become block content or reusable compositions. Header and site-wide options still use ACF, but the destination’s group names, keys and field structures differ. Destination fields to configure deliberately

  • CTA: ctas[].image_icon, heading, kicker, description, link plus columns and heading level. Keep section introductions/actions outside the repeater.
  • SOURCE Stories: channel, categories/tags, story count, layout, heading/action and card image ratio. Translate actual query intent rather than copying legacy query strings.
  • Trumba Events: calendar URL, event count, section heading and calendar link. A JSON event list does not replace all spud calendars or submission tools.
  • Slider: use only when sequential media browsing is intended. Map slides, accessible label, animation and playback settings; core Gallery is the closer visible-grid replacement.
  • Content Query: uses block attributes (post type, filters, curated IDs, table/grid settings), not an ACF repeater. It requires local registered content and suitable templates.
  • Site defaults: Page Options, Post Options, Social Media, Tracking & Analytics and Featured Image Caption need intentional setup. New defaults are not evidence that a corresponding legacy field existed.

Before switching themes, preserve a source-content export, resolve shared references and attachment IDs per site, then verify each converted page’s headings, links, captions, embeds and shared-update behavior in a test installation.
